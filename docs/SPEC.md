### 5.1 Minimal MV3 Permissions (Zero Store Friction)

- **Explicitly Excluded:** NO `<all_urls>`, NO `cookies`, NO `tabs`, NO `webRequest`, NO `history`, NO remote scripts.
- **Firefox Manifest (`manifest.firefox.json`):**

- **Edge / Chrome Manifest (`manifest.edge-chrome.json`):** Identical except `"background": { "service_worker": "background.js", "type": "module" }` and no `browser_specific_settings`.

### 5.2 Exact Color Math (`src/core/colorEngine.ts` & `src/pro/wcagAuditor.ts`)
- **OKLCH:** Implements Björn Ottosson's exact sRGB → linear sRGB → LMS → cube-root (`Math.cbrt`) → Oklab (`L, a, b`) → OKLCH (`L, C = hypot(a, b), H = atan2(b, a)`) forward and inverse transforms with `[0, 1]` sRGB clamping.
- **WCAG 2.2 Relative Luminance:** `L = 0.2126 * R_lin + 0.7152 * G_lin + 0.0722 * B_lin`, ratio `(max(L1, L2) + 0.05) / (min(L1, L2) + 0.05)`.
- **APCA `Lc` (W3 0.0.98G-4g):** Uses standard sRGB `2.4` power curve (`0.2126729 R + 0.7151522 G + 0.0721750 B`), soft-clamp below `0.022`, and normal/reverse polarity exponents (`0.56/0.57` vs `0.65/0.62`) scaled by `1.14`.
- **OKLCH Compliant Shade Solver:** Binary-searches OKLCH lightness `L` (preserving original hue `H` and chroma `C`) toward darker or lighter polarity to find the minimal perceptual shift that satisfies `>= 4.5` (AA) and `>= 7.0` (AAA).

### 5.3 Cross-Browser Eyedropper
- On Edge/Chrome (`'EyeDropper' in window`): invokes native `new window.EyeDropper().open()`.
- On Firefox (no `EyeDropper` API): popup sends `{ type: 'START_FIREFOX_PICKER' }` to `background.ts`, which calls `chrome.tabs.captureVisibleTab(undefined, { format: 'png' })` and injects `firefoxLoupe.ts` into the active tab via `chrome.scripting.executeScript`. Moving the cursor renders a crisp 11×11 zoomed Canvas loupe with live HEX/OKLCH readout; clicking saves the picked color directly to `chrome.storage.local` and copies to clipboard.
