ChromaLoom Documentation

Cross-browser Manifest V3 eyedropper, OKLCH math, WCAG 2.2 / APCA contrast solver, and Tailwind v4 token exporter.

1. Permissions & Security

ChromaLoom uses only activeTab, scripting, storage, and clipboardWrite. It never requests <all_urls> or cookies.

2. Pro Features

  • WCAG 2.2 & APCA Lc Auditor: Evaluate foreground/background pairs and click to solve the nearest AA or AAA shade in OKLCH space without shifting hue.
  • Token Export: Export palettes to Tailwind v4 @theme, CSS Custom Properties, or W3C Design Tokens JSON.
  • Gradient & Box-Shadow Inspector + Swatch Boards: Capture active-tab gradients/shadows and manage local swatch boards with JSON import/export.

3. Polar.sh License Activation

Open the ChromaLoom popup → Settings → paste your Polar.sh key. Your license state is cached locally in chrome.storage.local with 72-hour silent re-validation and a 14-day offline grace window.
